# 黎曼猜想研究包

更新日期：2026-08-14（Asia/Taipei）

## 結論狀態

**尚未得到黎曼猜想的有效證明。** 本目錄不把數值吻合、函數方程的對稱性，或尚未證明的關鍵引理冒充證明。

本次工作全程未搜尋網路。成果是：從高斯函數的 Poisson 求和出發，推導 ζ 函數的解析延拓、函數方程與 `Ξ` 的餘弦積分表示；再把黎曼猜想縮成一個明確、可證偽但仍未封閉的實零點義務。這是嚴格基礎與研究進度，不是千禧年難題的完成宣告。

## 檔案

- `01_foundations.md`：已完成且附理由的解析基礎、零點區域與等價降約。
- `02_attack_and_gap.md`：目前攻擊方向、已排除的錯誤捷徑、唯一承重缺口。
- `verify_numerics.py`：只用 Python 標準函式庫，檢查 theta 變換、兩種 `Ξ` 積分表示、核心正性與前幾個已知近似零點。
- `verification_report.json`：執行檢查後產生的結果；它是除錯證據，不是全域證明。

## 重現

在本目錄執行：

```powershell
python .\verify_numerics.py --output .\verification_report.json
```

程式成功只代表列出的有限檢查通過，不能推出「所有非平凡零點都在臨界線」。

## 有效完成的門檻

要把狀態改成「已證明」，至少必須同時具備：

1. 對每個非平凡零點的全稱論證，而非有限高度或有限網格檢查。
2. 對解析延拓、換序、微分、積分與極限交換的適用條件逐項交代。
3. 封閉 `02_attack_and_gap.md` 中標記為 **RH-K** 的義務，或提供另一條完整且不循環引用黎曼猜想的路徑。
4. 能排除臨界帶內所有離線零點；僅證明零點成對或四元組對稱不夠。
5. 經獨立逐行審核，沒有把猜測、數值證據或未證引理當成定理。
