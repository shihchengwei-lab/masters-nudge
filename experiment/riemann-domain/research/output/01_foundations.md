# 從 theta 變換到 `Ξ`：可審核的基礎推導

下文只證明標成「命題」的內容。最後的黎曼猜想本身沒有在本文被假設或宣告成立。

## 1. 命題與記號

令 `s = σ + it`。在 `σ>1` 定義

```text
ζ(s) = Σ_{n≥1} n^{-s}.
```

黎曼猜想（RH）是：若 `ζ(ρ)=0` 且 `0<Re(ρ)<1`，則 `Re(ρ)=1/2`。

定義

```text
θ(x) = Σ_{n∈Z} exp(-π n²x),     ψ(x) = Σ_{n≥1} exp(-π n²x) = (θ(x)-1)/2,
```

其中 `x>0`。

## 2. 命題：theta 變換

對每個 `x>0`，

```text
θ(x) = x^{-1/2} θ(1/x).                                      (2.1)
```

**證明。** 取 Schwartz 函數 `f_x(u)=exp(-πxu²)`。直接計算高斯 Fourier 變換得

```text
f̂_x(ξ) = x^{-1/2} exp(-πξ²/x).
```

將 `f_x` 週期化：`P_x(t)=Σ_{n∈Z}f_x(t+n)`。高斯衰減保證此級數及其各階導數在緊集上一致收斂，所以 `P_x` 是光滑的 1-週期函數。它的第 `k` 個 Fourier 係數是 `f̂_x(k)`；係數同樣以高斯速度衰減，Fourier 級數絕對收斂。令 `t=0` 即得

```text
Σ_n f_x(n) = Σ_k f̂_x(k),
```

也就是 (2.1)。∎

由 (2.1) 立刻得到

```text
ψ(x) = x^{-1/2}ψ(1/x) + (x^{-1/2}-1)/2.                     (2.2)
```

## 3. 命題：Mellin 表示、解析延拓與函數方程

在 `Re(s)>1`，逐項積分的絕對收斂給出

```text
Λ(s) := π^{-s/2} Γ(s/2) ζ(s)
      = ∫₀^∞ ψ(x)x^{s/2-1} dx.                              (3.1)
```

理由是令 `y=πn²x` 後，每一項積分為 `π^{-s/2}n^{-s}Γ(s/2)`；絕對值的總和由 `Σn^{-σ}` 控制。

把 (3.1) 在 `x=1` 分段，對 `(0,1)` 使用 (2.2)，再令 `u=1/x`，得到

```text
Λ(s) = 1/(s-1) - 1/s + J(s),                                (3.2)

J(s) = ∫₁^∞ ψ(x){x^{s/2-1}+x^{(1-s)/2-1}} dx.               (3.3)
```

核 `ψ(x)` 在 `x→∞` 時以 `exp(-πx)` 級數衰減。故對任一 `s` 的緊集，(3.3) 及其對 `s` 的任意階導數都由可積函數一致控制；因此 `J` 是整函數。(3.2) 遂給出 `Λ` 的亞純解析延拓，只有 `s=0,1` 的顯式單極點。

(3.2) 的右側在 `s↦1-s` 下不變，所以

```text
Λ(s) = Λ(1-s).                                              (3.4)
```

定義完成函數

```text
ξ(s) := (1/2)s(s-1)Λ(s)
      = 1/2 + (1/2)s(s-1)J(s).                              (3.5)
```

於是 `ξ` 是整函數，而且

```text
ξ(s)=ξ(1-s),        ξ(conj(s))=conj(ξ(s)).                  (3.6)
```

第二個等式直接來自 (3.3) 的實值核。

## 4. 命題：零點位於開臨界帶

先在 `σ>1` 使用絕對收斂的 Euler 乘積

```text
ζ(s)=∏_p(1-p^{-s})^{-1}.
```

它由唯一分解與絕對收斂得到，且其對數級數絕對收斂，故 `ζ(s)≠0`。

還要排除邊界 `σ=1`。若固定 `t≠0`，則對 `σ>1`，Euler 乘積的對數給出

```text
log{ζ(σ)^3 |ζ(σ+it)|^4 |ζ(σ+2it)|}
= Σ_{p,k≥1} [3+4cos(kt log p)+cos(2kt log p)]/(k p^{kσ}) ≥ 0,
```

因為 `3+4cos y+cos(2y)=2(1+cos y)^2≥0`。所以大括號內的量至少為 1。若 `ζ(1+it)=0`，設其零點階數為 `m≥1`；當 `σ→1+`，`ζ(σ)` 只有一階極點，其他因子至多有限或再提供零點，故該乘積是 `O((σ-1)^{4m-3})→0`，矛盾。因此 `ζ(1+it)≠0`。

由 (3.6)，`ξ` 在 `σ<0` 與 `σ=0` 的零點會映到 `σ>1` 與 `σ=1`，也不存在；而 (3.5) 給 `ξ(0)=ξ(1)=1/2`。因此 `ξ` 的零點都在 `0<σ<1`，且恰對應 `ζ` 的非平凡零點。

## 5. 命題：RH 的實零點形式

令

```text
Ξ(t) := ξ(1/2+it).
```

由 (3.6)，`Ξ` 是實係數的偶整函數；對實 `t`，`Ξ(t)` 為實數。

任取複數 `t=a+ib`，相應的 `s=1/2+it=(1/2-b)+ia`。所以

```text
RH  ⇔  Ξ 的每一個複零點 t 都是實數。                       (5.1)
```

這是精確等價，不是近似或單向暗示。

## 6. 命題：顯式正核餘弦表示

在 (3.3) 令 `x=e^{2u}` 並代入 `s=1/2+it`。設

```text
q(u)=2e^{u/2}ψ(e^{2u}).
```

則

```text
Ξ(t)=1/2-(t²+1/4)∫₀^∞ q(u)cos(tu)du.                        (6.1)
```

theta 變換在 `x=1` 的導數給 `θ'(1)=-θ(1)/4`，從而 `q'(0)=-1/2`。對 (6.1) 分部積分兩次；無窮遠邊界因雙指數衰減而消失，`u=0` 的邊界正好產生 `1/2`。因此

```text
Ξ(t)=∫₀^∞ K(u)cos(tu)du,                                    (6.2)

K(u)=Σ_{n≥1}(8π²n⁴e^{9u/2}-12πn²e^{5u/2})
               exp(-πn²e^{2u}).                             (6.3)
```

對 `u≥0`，令 `y=πn²e^{2u}≥π`，每一項可寫成

```text
4y(2y-3)e^{u/2}exp(-y)>0.
```

所以 `K(u)>0`，且它及所有導數都雙指數衰減。(6.2) 對所有複數 `t` 都絕對收斂並定義整函數。

若 `t=a+ib`，則零點條件精確等價於兩個實方程同時成立：

```text
∫₀^∞ K(u)cos(au)cosh(bu)du = 0,                             (6.4)
∫₀^∞ K(u)sin(au)sinh(bu)du = 0.                             (6.5)
```

RH 就是證明 (6.4)–(6.5) 在 `b≠0` 時沒有共同解。特別地，`a=0` 時 (6.4) 嚴格為正，故純虛軸上沒有 `Ξ` 零點；真正未解的是一般 `a≠0, b≠0` 的全域情形。
