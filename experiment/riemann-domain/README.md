# Riemann domain observational artifact

This directory retains the smallest self-contained contract needed to inspect the Riemann-domain routing experiment:

- `domain/riemann/`: the frozen base prompt and six mathematical lenses;
- `riemann_router.py`: deterministic lifecycle/specialist routing;
- [benchmark/](benchmark/README.md): de-identified reactions, aggregate counts, annotations, and the complete 17 traceable interactions;
- [benchmark/closures/](benchmark/closures/README.md): four bounded route-closure arguments with standalone verifiers and a hash manifest.

The complete research working tree and implementation snapshots were removed from the product branch and preserved in the verified [evidence archive release](https://github.com/shihchengwei-lab/masters-nudge/releases/tag/evidence-archive-2026-08-22).

This is not shipped plugin functionality and is not a claim of progress on the Riemann hypothesis.

## Observed workflow result

The full run produced 102 Nudge findings across three sessions. Reliable delivery receipts existed only in the final segment:

| Measure | Observed count |
|---|---:|
| Findings generated in the receipt-capable segment | 19 |
| Findings confirmed in the main model context | 17 |
| Traceable interactions with a direct, reframed, or delayed response | 13 of 17 |

The denominator is 17 confirmed injections, not all 102 findings. There was no control arm, randomization, blinded scoring, or mathematical peer review. A visible response after injection is temporal evidence, not a causal effect size.

Start with the [benchmark report](benchmark/README.md), then inspect the [complete interaction table](benchmark/interactions.md) and [closure certificate boundaries](benchmark/closures/README.md).

## Verification

Run from the repository root:

```powershell
python -m unittest experiment/riemann-domain/tests/test_archive.py -v
python -m unittest experiment/riemann-domain/benchmark/test_benchmark.py -v
python -m unittest experiment/riemann-domain/benchmark/closures/test_closures.py -v
```

The closure suite optionally uses `python-flint`; tests that require it report `skipped` when the package is unavailable. The archive and benchmark tests remain meaningful without that optional dependency.
